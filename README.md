# Практическая работа №4 — ShopSystem

Учебный проект маркетплейса в рамках практической работы №4 по ИСРПО: REST API на ASP.NET Core, база данных SQLite (EF Core) и клиентское настольное приложение на WPF.

## Реализованный функционал

- **Каталог товаров**:
  - Просмотр списка товаров гостем и авторизованным покупателем;
  - Поиск товаров по наименованию и описанию;
  - Фильтрация каталога по категориям и диапазону цен;
  - Отображение рейтинга и наличия на складе.
- **Пользовательский раздел**:
  - Регистрация и авторизация покупателей;
  - Корзина с расчетом итоговой стоимости и управлением количеством;
  - Список избранных товаров;
  - Просмотр и добавление отзывов к товарам с выставлением оценок (1–5);
  - Оформление заказа: выбор способа получения (самовывоз из ПВЗ или курьерская адресная доставка только при заказе свыше 600 ₽).
- **Панель администратора**:
  - Управление каталогом товаров (добавление новых позиций, редактирование параметров, переключение доступности в каталоге);
  - Управление категориями товаров (добавление, переименование);
  - Управление пунктами выдачи заказов (добавление, редактирование адреса и статуса активности);
  - Просмотр и изменение статусов заказов;
  - Модерация отзывов покупателей (удаление некорректных отзывов).
- **Архитектура и тестирование**: многослойная архитектура (Core, Application, Infrastructure, Api, Desktop), автоматические модульные тесты xUnit для бизнес-логики.

## Структура решения и архитектура

- `src/ShopSystem.Core` — доменные сущности и базовые модели (`Product`, `Order`, `OrderItem`).
- `src/ShopSystem.Application` — контракты репозиториев (`IShopRepository`) и сервисы бизнес-логики (`ProductService`, `OrderService`).
- `src/ShopSystem.Infrastructure` — реализация `InMemoryShopRepository`. Слой предназначен для изоляции и тестирования бизнес-логики без привязки к СУБД, а также для работы консольного демонстрационного приложения.
- `src/ShopSystem.ConsoleApp` — консольное приложение, прототип для локальной проверки бизнес-сценариев каталога и заказов на основе `InMemoryShopRepository`.
- `src/ShopSystem.Api` — основной REST API бэкенд на ASP.NET Core Minimal API, использующий Entity Framework Core и реляционную базу данных SQLite (`ShopDbContext`) для постоянного хранения данных пользователей, каталога, заказов и отзывов.
- `src/ShopSystem.Desktop` — клиентское настольное приложение на WPF (XAML), взаимодействующее с REST API.
- `tests/ShopSystem.Application.Tests` — модульные тесты xUnit для слоя `ShopSystem.Application` с использованием `FakeShopRepository`.

## Инструкция по сборке и запуску

### Сборка и запуск тестов

В корне проекта:

```powershell
dotnet restore .\ShopSystem.sln
dotnet build .\ShopSystem.sln
dotnet test .\ShopSystem.sln
```

### Запуск сервисов

Для демонстрации работы приложения рекомендуется открыть два терминала:

1. **Запуск серверной части (REST API):**
```powershell
dotnet run --project .\src\ShopSystem.Api -- --urls http://127.0.0.1:5077
```

2. **Запуск клиентской части (WPF):**
```powershell
dotnet run --project .\src\ShopSystem.Desktop
```
